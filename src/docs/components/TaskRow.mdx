# Task row

`<pastis-task-row>` is one task in a list: a round completion toggle, the title, a meta line
(due date, repeat, flag, priority, subtasks, tags) and optional actions. It is the row of a
Reminders-style list, not a form control; use `<pastis-checkbox>` in forms.

<Canvas of={TaskRowStories.List} />

## Usage

- **Put rows in a list.** The host has `role="listitem"`; render the rows inside an element with
  `role="list"` (or a `<ul>`).
- **The title is `task-title`** (property `taskTitle`), not `title`: `title` is the browser's
  tooltip attribute. An empty title is named “Untitled task”.
- **Completion.** The toggle is a checkbox named “Complete” plus the title (`toggle-label` overrides
  it); click or Space toggles it. It fires a cancelable `pastis-toggle` with the new `done`. To
  keep the row controlled (for example until a save succeeds), call `preventDefault()` and set
  `done` yourself.
- **Opening.** The title is a button firing `pastis-open`; its hit area covers the meta line.
- **Meta.** Set `due` and `subtasks` as text the app has formatted (“Today 14:00”, “2/5”),
  `overdue`, `repeats` and `flagged` as booleans, `priority` 0–3, `tags` as an array (a
  property, or a JSON array attribute). Screen readers hear the meta as the title's
  description: “Buy oat milk, button, Today 14:00, Flagged”.
- `indent` shows a subtask one level in; `disabled` disables the toggle and the title.
- **Reordering.** `reorderable` adds a handle at the end of the row (“Reorder” plus the title,
  `reorder-label` overrides it) for [`<pastis-sortable>`](?path=/docs/basics-sortable--usage),
  which turns drags, taps and arrow keys on it into `pastis-reorder`.
- **Actions.** Put buttons in the `actions` slot; they come after the title in the Tab order.
- **Compact density** (`density="compact"`) for desktop lists: one 32 px line of toggle · title
  (ellipsis) · aligned meta columns · actions. Put the cells in the `meta` slot and set the tracks
  once on the list with `--pastis-task-row-columns` (`[status] 4rem [due] 6rem [list] 7rem`); a
  cell picks its track with `grid-column` (`style="grid-column: due"`), or takes the next one.
  Slotted cells replace the built-in visible meta, but the meta properties still describe the
  title, so mark repeating cells `aria-hidden="true"`. The actions show on hover and while focus
  is inside the row (always on touch screens), over the cells.
- **Selected** (`selected`) highlights the row whose details are open. It is styling only: a
  list item takes no `aria-selected`.

## Do

```html
<div role="list" aria-label="Personal">
  <pastis-task-row task-title="Buy oat milk" due="Today 14:00" flagged></pastis-task-row>
  <pastis-task-row task-title="Renew passport" due="Yesterday" overdue priority="3">
    <pastis-button slot="actions" variant="ghost" size="sm" aria-label="Delete Renew passport">Delete</pastis-button>
  </pastis-task-row>
</div>
```

```js
// Controlled: only mark done once the change is saved
row.addEventListener('pastis-toggle', async (e) => {
  e.preventDefault();
  await save({ done: e.detail.done });
  row.done = e.detail.done;
});
```

```html
<div role="list" aria-label="Platform" style="--pastis-task-row-columns: [status] 4rem [due] 6rem">
  <pastis-task-row density="compact" task-title="Ship the release" due="Today" selected>
    <span slot="meta" aria-hidden="true" style="grid-column: status">Doing</span>
    <span slot="meta" aria-hidden="true" style="grid-column: due">Today</span>
    <pastis-button slot="actions" variant="ghost" size="sm" aria-label="Flag Ship the release">Flag</pastis-button>
  </pastis-task-row>
</div>
```

## Don't

```html
<!-- Don't use title for the text: it is a tooltip and the row shows nothing -->
<pastis-task-row title="Buy oat milk"></pastis-task-row>

<!-- Don't set the column tracks per row: rows only line up when they share one definition -->
<pastis-task-row density="compact" style="--pastis-task-row-columns: auto auto"></pastis-task-row>

<!-- Don't render rows outside a list -->
<div><pastis-task-row task-title="Buy oat milk"></pastis-task-row></div>

<!-- Don't pass raw dates: format them for people first -->
<pastis-task-row task-title="Buy oat milk" due="2026-11-25T14:00:00Z"></pastis-task-row>
```
