# Pastis Design System

Pastis is a library of framework-agnostic web components built with [Lit](https://lit.dev).
Every component is a native custom element, so it works in plain HTML, React, Vue, Svelte
or any other stack — no wrappers needed.

The system is driven by design tokens (colour, typography, spacing and motion) and ships
with a light and a dark theme. Accessibility is treated as a requirement: components aim
for WCAG 2.2 AA, with keyboard support and visible focus throughout.

## What's inside

| Section | What you'll find |
| --- | --- |
| **Foundations** | Tokens, swatches and spec tables |
| **Basics** | Buttons, inputs, quick add, recurrence picker, sortable, date and time fields, checkboxes, toggles, badges, tags, icons… |
| **Navigation** | Main navigation, tab bar, tabs, breadcrumbs, accordion, pagination |
| **Feedback** | Alerts, toasts, progress, spinners, skeletons, empty states |
| **Overlay** | Modal, drawer, tooltip |
| **Layout** | Card, section, divider |
| **Data Display** | Tables, task rows, stat cards, code blocks |
| **Marketing** | Hero, cookie banner and other page-level patterns |

Use the sidebar to browse each component. Every story has a **Docs** tab with its
properties, and the **Controls** panel lets you try them out live.
